# Card maker

Utility per generare in batch tesserini con nome.

Parte da un modello PDF o Illustrator (.ai) e crea un PDF per ogni nome, sostituendo il testo del modello. Tutto il resto del modello resta identico. Funziona interamente nel browser: i file non vengono caricati da nessuna parte.

## Uso

1. Apri `index.html` nel browser.
2. Scegli il modello. Il testo che contiene viene sostituito dal nome, con la stessa dimensione e posizione.
3. Inserisci i nomi, uno per riga, oppure importa un file .txt o .csv.
4. Scarica uno ZIP con un PDF per nome, oppure un unico PDF con tutte le tessere.

Il modello deve contenere il testo come testo, non convertito in tracciati.
